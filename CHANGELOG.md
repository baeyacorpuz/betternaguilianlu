# Changelog

All notable changes to Better Naguilian are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The same changes, with dates and sources for data corrections, are published at `/updates`.

## [1.0.0] - 2026-11-17

### Added

- Service directory built from the 2023 Citizen's Charter: 76 services, each with a detail page and a link to the charter page.
- Ranked service search (⌘K and the `/services` page) with category filters and shareable URLs.
- Accuracy feedback on service pages, with a pre-filled email or GitHub issue for reports.
- Emergency hotlines, Legislative and Transparency pages, and a friendly 404 page.
- Government section: leadership, history, officials and barangays, from the official municipal site.
- Contact page with community-built LGU sites, and an About page explaining the volunteer project.
- First-visit welcome dialog, light and dark themes, and an installable PWA that works offline.
- Versioning: the footer shows the version and build date, and `/updates` lists what changed.
